# 2026-10-21 MTG資料: LongVideoBenchのタスク整理

## 0. 今日のMTGで相談したいこと

1. **字幕を手がかりにするT系7カテゴリを、当面は評価から外してよいか。**（「普通は全タスクで評価する」と言われているため）
2. **LongVideoBenchを「動画を先頭から順に見て、最後に質問を渡す」形のオンライン処理として評価してよいか。**
3. **結果を、全体の正答率に加えて「L1/L2別」と「参照場面から質問までの距離別」に分けて出す方針でよいか。**

## 1. 結論

- LongVideoBenchの質問は **17カテゴリ** あり、**L1 Perception（1つの場面）8種** と **L2 Relation（複数の場面の関係）9種** に分かれる。
- 17カテゴリのうち **7カテゴリ（T系）は、字幕のセリフで場面を指す**。字幕を読まないと、どの場面のことか分かりにくい。
- LongVideoBenchは **オフライン処理向けのベンチマーク**。各質問に「いつ質問されるか」の時刻がなく、動画全体を見てから答える前提になっている。
- **全問がreferring reasoning（参照推論）**。質問は「動画のどこかの場面を言葉で指す説明」から始まり、その場面を見つけてから答える。
- 今回は **質問を動画の最後に初めて渡す** 形にする。そうすると、指された場面はいつも質問より前にあり、**質問を知らないまま残した記録から場面を探す** 問題になる。

---

## 2. LongVideoBenchのタスク

### 基本情報（原文で確認、件数はローカルデータで集計）

- 多肢選択式（選択肢は主に4〜5個）。評価は正答率。
- 分割は **val（1,337問、正解あり）** と **test（5,341問、正解は非公開）** だけ。学習用の分割はない。
- 動画の長さは4グループ：8–15秒、15–60秒、180–600秒、900–3600秒。
- ジャンルは10種類（映画のあらすじ解説、旅行、Vlog、料理、ニュース、知識系5種）。
- 各問題のJSONに、カテゴリ（`question_category`）と L1/L2（`level`）のラベルがある。

### カテゴリ名の読み方

- 1文字目：場面を指す手がかり（**S**=場面の見た目、**E**=出来事、**O**=物体、**T**=字幕）
- 最後の文字：答えの種類（**E**=出来事、**O**=物体、**A**=属性、**S**=場面・字幕）
- 「2」は「その時点の」、「3」は「前後の」

※ 読み方はカテゴリ名からの推論で、論文に明記はない。

### L1 Perception（知覚）：1つの場面で見えるものを問う

| 略号 | 何を問うか | val |
| --- | --- | ---: |
| S2E | 場面の説明 → その場面で起きている出来事 | 93 |
| S2O | 場面の説明 → その場面にある物体 | 72 |
| S2A | 場面＋物体 → その物体の色・形など | 88 |
| E2O | 出来事 → それに関わる物体・人 | 65 |
| O2E | 物体 → それが映っているときの出来事 | 87 |
| T2E | 字幕 → その字幕と同時の出来事 | 65 |
| T2O | 字幕 → そのとき映っている物体 | 76 |
| T2A | 字幕＋物体 → そのときの物体の色・形など | 79 |

### L2 Relation（関係）：複数の場面の関係を問う

| 略号 | 何を問うか | val |
| --- | --- | ---: |
| E3E | 出来事 → その前・後の出来事 | 94 |
| O3O | 物体 → その前・後に現れる物体 | 66 |
| SSS | 複数の場面 → 正しい順序 | 97 |
| SOS | 場面＋物体 → その物体が再び現れる別の場面 | 81 |
| SAA | 2つの場面＋物体 → その間の属性の変化 | 72 |
| T3E | 字幕 → その前・後の出来事 | 73 |
| T3O | 字幕 → その前・後に現れる物体 | 74 |
| TOS | 場面＋物体 → その物体が再び現れたときの字幕 | 73 |
| TAA | 2つの字幕＋物体 → その間の属性の変化 | 82 |

- 原論文によると、**SSSはすべてのモデルで最も難しい**（誤答の選択肢が、正しい順序を並べ替えたものになっているため）。L2はL1より難しい。
- 質問の後半（「What is this man doing?」など）の言い回しは、カテゴリごとにほぼ決まっている（ローカルデータで集計）。そのため、**どんな質問が来るかは予習しやすい**。予習できないのは「どの場面を聞かれるか」のほう（推論）。

## 3. 字幕が必要な問題がある

- **T系7カテゴリ（T2E, T2O, T2A, T3E, T3O, TOS, TAA）は、字幕のセリフを使って場面を指す。** 例：「When the subtitle '...' appears, what is X doing?」
- そのため、字幕を読まないと、どの場面のことかを特定しにくい（推論）。TOSは答えそのものが字幕の文。
- 公式の入力は、フレーム画像と字幕を交互に並べたもの。字幕は動画とは別のファイルで、動画によっては時刻のずれを直す必要がある（`starting_timestamp_for_subtitles`）。
- 問題数：T系は val 522問。外すと、残るS/E/O系10カテゴリは **val 815問（約61%）**。

**相談：** 第1版では映像からのイベント記録に集中したいので、T系は当面外したい。字幕を使う場合は、字幕も時刻順に届くものとして渡す処理が必要になる。

---

## 4. LongVideoBenchはオフライン処理向けのベンチマーク

- 各問題のJSONには **「いつ質問されるか」の時刻がない**（ローカルデータで確認）。
- 公式の評価では、**動画全体から一様にフレームを取り、字幕と一緒に一度に入力し、最後に質問と選択肢を置く**（原文・公式ローダーで確認）。
- つまり、モデルは質問を見るときに動画全体にアクセスでき、必要なら場面を見直せる。

これに対して、Streaming（オンライン）向けのベンチマークは、各質問に「この時刻に質問が来たとして答える」というタイムスタンプを持っている。

### 今回の扱い

- **動画を先頭から順に1回だけ読み、質問と選択肢は動画の最後に初めて渡す。**
- 記録の段階では、質問は見せず、予習の情報（どんな種類の質問が来そうか）だけを渡す。
- 原論文や既存手法の数字は、動画全体を見られる条件での結果なので、**私たちの結果と同じ条件ではない** ことを明記する。

---

## 5. Referring reasoning（参照推論）

### 意味

- **referring query（参照文）**：質問の最初に付いている、動画の1つまたは複数の場面を言葉で指す説明。
  - 例：「On the sea, a woman wearing sunglasses ... is sitting in a cart ...」（場面の説明）＋「What is this woman doing?」（短い質問）
- **referring reasoning（参照推論）**：参照文を読んで、長い動画の中から **指された場面を見つけ**、**その場面について推論して答える** タスク。LongVideoBenchが新しく提案したもの（原文で確認）。
- LongVideoBenchでは **17カテゴリすべてがreferring reasoning**。特定のカテゴリだけを指す言葉ではない。
  - L1は1つの場面、L2は複数の場面を指す。valの `position`（指された場面のフレーム番号と見られる）も、L1はほぼ1点、L2はほぼ2点以上になっている。
  - 例外：SSSの大半とO3Oの一部は、場面の説明が質問ではなく選択肢の側に書かれている。

### 今回のケースでの扱い

- 質問を動画の最後に渡すので、**指された場面はいつも質問より前（過去）にある**。
- 質問が来たときには、動画は見直せない。**質問を知らないまま残した記録** と参照文を照らし合わせて、場面を探すことになる。
  - → 記録に何を残しておくか（予習した観点）で、場面を見つけられるかが変わる。ここが手法の効きどころになると考えている（推論）。
- 長い動画では、指された場面が質問よりかなり前にある。**900–3600秒のグループでは、最後に指された場面から動画の終わりまで、中央値で約673秒（約11分）**（valをローカルで集計）。
- ただし、LongVideoBenchは「離れていること」を保証して作られたベンチマークではない。短い動画（60秒以下）も val の約27%（361問）ある。

### 既存の報告との違い

- LongVideoBenchをオンライン処理で解いた手法は、調べた範囲で9本あったが、**すべて全体の正答率だけ** を報告していた。
- **カテゴリ別や、参照場面からの距離別に分けたオンライン手法は見つからなかった。** 近いのはオフライン手法（LongVU-TTT：時間差別、LazySloth：質問の種類別）だけ。
- 全体の正答率に加えて、**L1/L2別・カテゴリ別・距離別** に出せば、既存の報告とは違う見せ方ができる。

---

## 6. 言えること / まだ言えないこと

### 言えること

- 17カテゴリ（L1 8種、L2 9種）があり、全問がreferring reasoning。
- 各質問に「いつ質問されるか」の時刻はなく、公式の評価はオフライン（動画全体を一度に入力）。
- T系7カテゴリは字幕のセリフで場面を指す。

### まだ言えないこと

- 「LongVideoBenchは離れた証拠が必要な問題である」とは言い切れない。離れていることは保証されておらず、短い動画も多い。
- 約11分という距離は、`position` をフレーム番号とみなした推論に基づく（公式の説明はない。valの1,335/1,337問で動画の長さに収まることは確認済み）。
- 「距離別に分けたオンライン手法がない」は、決めた手順で探した範囲での結果。
- T系を外したときに、字幕なしで解ける問題がどれくらいあるかは未確認。

## 7. 次に進む候補

- 第1版の評価対象：S/E/O系10カテゴリ（val 815問）。まず出来事系（S2E, O2E, E3E, SSS）で記録と回答を作り、物体系（S2O, E2O, O3O, SOS）を足す。
- 属性系（S2A, SAA）は、テキストの記録では落ちやすいと考えて、別枠で報告する（実際に落ちるかは実験で確かめる）。
- 結果の出し方：全体、L1/L2別、カテゴリ別、動画の長さ別、参照場面からの距離別。
