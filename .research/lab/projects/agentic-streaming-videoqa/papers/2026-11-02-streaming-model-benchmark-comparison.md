# Streaming モデルの精度比較（論文調査）

- 作成: 2026-11-02（AI が調査）
- 対象: サーベイ（Yang et al. 2026）の Awesome リストの全モデル、これまでの分類メモの論文、2026年5〜11月の新しい論文。計116本
- 数値: 各論文の arXiv HTML / PDF の表から直接読んだ、**提案手法自身の報告値**（他論文による再評価は使わない）。WebFetch の要約は使っていない

## 結論：いま一番強い Streaming モデル（2026-11-02 時点）

数値は各論文の自己申告で、評価条件（フレーム数・fps・基盤モデル・Overall の定義）がそろっていない。以下は、その前提で読んだときの結論。

1. **OneStreamer は、今回比較したモデルの中で特に有力な実行候補**。
   - Qwen3-VL-4B を初期化した4Bモデルで、StreamingBench Real-Time 86.9 は本調査で確認した最高値。OVO-Bench Overall 72.1、OVBench 66.8、ODV-Bench 71.3 も報告している
   - ただし全指標で首位という意味ではない。たとえば本表では OVO-Bench Overall は Watch-Think-Interact の報告値 73.6 が上回り、OVO Real-Time も他手法に上回られている。Overall の定義や評価条件も一律ではない
   - 同論文は8つのオンライン動画理解・応答ベンチマークで比較対象中最高と報告しているが、これは論文内の比較範囲での主張。本調査の116本を横断した全指標首位とは区別する
2. **次点**:
   - MOSS-VL-Realtime（11B）: OVO 70.2。ただし自前評価で、768フレームの全履歴を見る
   - ViSS+TVS（Qwen3-VL-8B）: OVO 69.77 / SB-RT 86.33
   - StreamReady（Qwen2-VL-7B）: OVO 68.2
   - StreamingBench の全18タスク Overall の最高は Live-OPSD の 76.0（Qwen3-Omni-30B-A3B、音声つきの自前評価）
3. **学習なしで一番強いのは D-HSM**（SB-RT 85.4 / OVO 66.8、Findings of EMNLP 2026）。次いで SelectStream（OVO 67.03、メモリ側だけ学習、NeurIPS 2026）
4. **記憶の形で見ると、上位はテキスト系と「窓のみ」系**。KVキャッシュ系（HERMES、InfiniPot-V など）は SB-RT 76〜81 程度にとどまる

### OneStreamerをまず動かす根拠

「多くの論文が使うベンチマークで幅広く高精度」という説明は、次のように数値を添えると正確。

| 根拠 | OneStreamerの報告値 | 比較・読み方 |
|---|---:|---|
| StreamingBench Real-Time | **86.9** | 本調査で確認した最高値。次点のViSS+TVSは86.33で、差は+0.57ポイント |
| OVO-Bench | Overall **72.1**; Real-Time **81.4**; Backward **77.9**; Forward **56.9** | 3区分の性能を報告。ただし本表ではOverall 73.6の報告例があり、OVO Real-Timeにもより高い値があるため「OVO首位」とは言わない |
| OVBench / ODV-Bench | **66.8 / 71.3** | StreamingBench・OVO以外のオンライン理解ベンチマークにも数値がある |
| ProactiveVQA / OmniMMI / OVO-Timing / ViSpeak | **48.7 / 36.6 / 41.6 / 2.87** | 即時QAだけでなく、応答タイミング・対話を含む論文内の8ベンチマーク評価をカバー |
| Qwen3-VL-4B同士の比較 | SB-RT **81.8→86.9** (+5.1); OVO **58.8→72.1** (+13.3); OVBench **55.4→66.8** (+11.4); ODV **57.6→71.3** (+13.7) | 原論文の同サイズ基盤モデル比較。いずれもOneStreamer側が高い |

順位以上に、本研究の方向と合う根拠は**メモリのアブレーション**にある。原論文は同じチェックポイント・直近16フレームの設定で、生成キャプションを保持しないFIFOと保持するPHCMを比較している。OVO Backward の ASI は **63.5→71.6（+8.1ポイント）**、OVO Real-Time は **80.9→81.4（+0.5）**、StreamingBench Real-Time は **86.3→86.9（+0.6）**。つまり、過去フレームを見返さずテキスト記録を足す設計が、過去情報のQAを改善し、少なくともこの比較では現在の認識精度を落としていない。これは「ストリーム中に記録を作り、後の質問に使う」という本プロジェクトの関心を試す、直接的な仮説根拠になる。

実行候補としての追加根拠は、(1) Qwen3-VL-4Bベースのため比較対象を特定しやすい、(2) キャプション記録を直近の視覚窓と併用する構造が明示され、何を動かすか説明しやすい、(3) 論文にコード・モデル・データへの公式リンクがある、(4) 360秒のStreamingBench動画・H200 1基という論文内計測で、メモリ更新の平均0.636秒/回（1秒ごとの入力より短い）と報告されている点。最後の速度値は著者の計測環境に限られ、手元のGPUでの実時間動作を保証するものではない。

**発表での短い言い方:** 「まずOneStreamerを動かすのは、StreamingBench Real-Timeで本調査中最高の86.9を報告し、OVO・OVBench・ODVなど計8つのオンラインベンチマークを評価しているためです。加えて、同一モデルのアブレーションで、テキスト記録の保持によりOVO Backward ASIが63.5から71.6へ上がり、Real-Time指標も維持・微増しています。ベンチマーク順位だけでなく、私たちが調べたい“ストリーム中に作った記録が後のQAに効くか”を検証できるため、最初の再現対象に選びます。」

出典: [OneStreamer原論文（arXiv HTML）](https://arxiv.org/html/2610.01762v1)（Table 1–3、効率評価）、[公式プロジェクトページ](https://mcg-nju.github.io/OneStreamer/)。本調査表の他手法との横断比較値は各論文の自己報告値であり、同一条件での再評価ではない。

### 数値を読むときの注意

- **メモリを持たないモデルでも十分強い**。Qwen3-VL-8B に直近4フレームだけを入れると、OVO Real-Time 81.4 / SB-RT 80.6（SimpleStream）。そのため OVO-Bench Real-Time と StreamingBench Real-Time は、記憶の良し悪しよりも基盤モデルの強さを主に測っている
- **差が付くのは OVO-Bench Backward だが、HLD（ハルシネーション検出）に左右されやすい**。HLD がほぼ満点の手法がある（OneStreamer 99.5、StreamScout 98、SPARE 90）。Backward の高さには HLD の寄与が大きい可能性がある
- **OVO-Bench Overall の定義がそろっていない**。Forward を除いて RT と BT だけで平均する論文が多い（SPARE 77.78、StreamScout-R 76.63 はこの定義なので、3カテゴリ平均の値とは比べられない）
- **長い間隔の記憶を測るベンチマーク（EgoProbe、EGOSTREAM など）で手法を評価している論文は、今回の範囲では見つからなかった**。ここでの「最強」は、短めの Streaming ベンチマークでの強さ
- **このプロジェクトとの関係**: OneStreamerはSB-RTの本調査最高値と、記録保持の有効性を示す同一モデル内アブレーションを持つため、まず実行する候補として妥当。ただし横断表の全指標で首位ではない。EventMemAgent（OVO 60.75 / SB-RT 77.0）は中位

## 論文の目的による分類（サーベイ原文の全件）

### 分類の使い方

- 論文は **VideoQA / 非QA / 混合** と **Reactive / Proactive** を別々の軸として確認する。上の8分類は主としてモデルの技術的アプローチを示す。
- ベンチマークは今回使いたい能力に合うものを選び、データセット名だけでなく評価プロトコル・指標まで確認する。
- 学会列は個別の正式な論文ページを確認できた場合にそのURLへリンクした。査読版の確認ができない論文は元のpreprint等へのリンクを残し、学会列に確認状況を記した。
