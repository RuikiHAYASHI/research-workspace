# OVBench と ODV-Bench のまとめ

- OVBench: VideoChat-Online の論文（OneStreamer の文献 [8]、CVPR 2025）で作られたベンチマーク。ODV-Bench: StreamForest の論文（文献 [39]、NeurIPS 2025）で作られたベンチマーク。どちらも OneStreamer と同じ MCG-NJU（南京大学）のグループのもの
- 見たもの: OneStreamer の論文（表1・表10・表11・表16・付録 D）、公式コード（`VLMEvalKit/vlmeval/dataset/ovbench.py`・`ovbench_new.py`・`odvbench.py`・`odvbench_bbox1000.py`）、公式が読む注釈（`json_data/ovbench/..._bbox1000.json`、`json_data/odvbench/ODVbench_bbox1000.json`）、再現の ODV-Bench の採点結果（`judge_outputs/OneStreamer-4B/odvbench/repro-full/paper/odvbench/scored.json`）
- 2 つの元の論文（VideoChat-Online・StreamForest）はまだ読んでいない
- 書いた人: AI（Claude）、林の依頼（2026-11-06「次は OVBench と ODVBench」）
- 記号: [論文] OneStreamer の原文、[データ] 注釈を見て数えたこと、[実験] 公式コードや再現の出力で確かめたこと、[AI] AI の考え（未検証）

## 1. 2 つに共通すること：記憶を使わず、質問の時点までの映像をまとめて 1 回で答える

[論文・実験] 表1 では「Perception & Memory」側に入っているが、OneStreamer の記憶（`</Observe>`・`</Summary>`）は使わない。公式コードは、OVBench・ODV-Bench を VLMEvalKit の普通の動画 QA の処理に回す（`run_script/worker.py`。記憶を使う処理に回るのは OVO-Bench・StreamingBench だけ）。

- 質問ごとに決まった区間の映像を、一定の fps でコマに切って、全部まとめてモデルに入れ、1 回だけ答えさせる
- 区間の始まり（[データ]）: ODV-Bench は 6,348 問すべてが動画の先頭（0 秒）から。OVBench は New AVA 以外の 5,414 問のうち 5,366 問が先頭からで、48 問は注釈の `start` が 0 より後。New AVA の 1,396 問は直前 120 秒だけを、最大 64 枚に間引いて入れる（2fps なら 240 枚になるところ）。それ以外は区間のコマを fps どおりに全部入れる（上限 4,096 枚に届く問題はない）
- 区間は「質問の時点まで」なので未来は見えない。ただし途中で記憶を作ったり、逐次に処理したりはしない。[AI] 実際にやっていることは、区間を切り取ったオフラインの動画 QA に近い（林の 11/03 の判断と同じ）
- 答えはすべて選択肢の記号（2〜4 択）。採点は記号が一致するか

| | OVBench | ODV-Bench |
|---|---|---|
| fps（付録 D） | 2fps（New AVA だけは直前 120 秒から最大 64 枚） | 4fps |
| 区間の長さ（[データ]、中央値） | 約 83 秒（タスクによって 14〜128 秒） | 約 10 秒（最大 90 秒） |
| プロンプトに入るもの（[実験]） | 「この動画は○秒前から今（○秒）までの N 枚」という時刻の説明 ＋ 質問 ＋ 選択肢 | 「運転の分析の専門家として」という役割 ＋ **タスク名とサブタスク名** ＋ 区間の秒数 ＋ 質問 ＋ 選択肢 |
| 箱（BBox）の書き方 | 0〜1000 の整数（Qwen3-VL の座標の書き方に合わせた版の注釈。ファイル名の `bbox1000`） | 同じく 0〜1000 |
| 指標 | 16 サブタスクの正答率の**重みなし平均** | 全問の正答率（**問題数で重み付け**）。区分の平均も同じ |
| 問題数 | 6,810 | 6,348 |

### 気づいたこと

- [データ] **AT（Action Trajectory）は映像を見なくても解ける**。230 問すべてで、質問に書かれた箱の座標が、正解の選択肢の中にだけそのまま出てくる（公式の注釈で確認）。OneStreamer 99.1・Qwen3-VL 95.7 が高いのはこのため（[AI]）
- [論文] 元の Qwen3-VL-4B から大きく伸びたのは、OES（+51.4）・OP（SP、+33.3）・AR（+33.1）・TR（+19.0）・AS（+11.1）・GSP（+11.7）。どれも箱の座標や時間帯を答える問題。逆に MP・SV・OP（THV）・PR は伸びていないか、少し下がっている
- [AI] 学習データ（OneStreamer-1M）には、OVBench を作った VideoChat-Online の学習データ（VideoChat-OL）と、ODV-Bench を作った StreamForest の学習データが入っている（表6、読書ログ）。箱の座標で答える問題の大きな伸びは、同じ形式の問題で学習した効果かもしれない。同じ動画が入っているかは確認していない
- [データ] SL（29.8）と MP（24.0）は、4 択の偶然（25%）とほとんど変わらない

### 再現の状況

まだ回していない。キューで OVO-Bench（Backward → Real-Time → Forward）のあと。New AVA の 1,396 問（6 サブタスク）だけ注釈を作り直している（[再現ログ](../experiments/2026-11-03-onestreamer-reproduction.md) §8.1）。残りの 5,414 問は公式の注釈のまま。

### 気づいたこと

- [実験] **プロンプトにサブタスクの名前がそのまま入る**（例: `Subtask: Risk Prediction`）。何を聞かれているかの手がかりになる。比べた他の手法も同じ設定で評価したかは書かれていない（付録 D は「元の設定と OneStreamer の設定の両方で評価し、高い方」）
- [実験] 選択肢の並びは注釈の順のまま（並べ替えなし）。2 択では、正解の偏りがそのまま出る
- [実験] **RP（Risk Prediction）は、いつも「No」と答えるより悪い**。正解は「No」が 73%（682/929）なのに、再現の予測は「Yes」が 63%（585/929）。いつも「No」なら 73.4 のところ、51.3。論文の他の手法もみな 39〜68 で、このタスクは全体に解けていない（表11）
- [実験] DP（Distance Prediction）は「近づいている」と答えすぎる（予測の 82%、正解では 53%）。DDM（28.7）は 4 択の偶然とほぼ同じで、元の Qwen3-VL-4B（31.4）より低い。選択肢 D を選んだのは 303 問中 21 問だけ（正解が D は 74 問）
- [実験] HD（Hallucination detection）の正解は全問「Unable to say.」だが、OVO-Bench の HLD と違って、この選択肢はほかのタスクの 73 問にも出てくる（正解は 2 問だけ）。再現でその 73 問のうち「Unable」を選んだのは 4 問で、正答率 90.4。[AI] HD の 90.2 は「選択肢があれば選ぶ」だけではなく、見分けられていると考えてよさそう
- [論文] 元の Qwen3-VL-4B からの伸びが大きいのは HD（+58.5）・LP（+17.9）・KIE（+17.0）・PTM（+16.2）。ARA は 11.5 点下がっている

### 再現の状況

完了（11/03）。**71.36（論文 71.3）**。区分の平均も 68.5 / 76.1 / 65.8（論文 68.4 / 76.0 / 65.8）。公式の注釈と公式の採点で、サブタスクの単位まで一致した。[AI] 記憶を使わないベンチなので、これは「重み・前処理・プロンプトが論文と同じ」ことの確認になる。記憶の仕組みの確認にはならない。

## 4. 表1 を説明するときに言えること

- OVBench と ODV-Bench は表1 で「Perception & Memory」側にあるが、OneStreamer の記憶は使わず、質問の時点までの映像をまとめて入れて 1 回答える。伸び（+11.4・+13.7）は、記憶ではなく学習（データと PSTL）の効果
- [論文] ただし著者は、記憶を書く学習データ 60K を抜くと、この 2 つも少し下がる（66.8 → 65.7、71.3 → 70.5、表16）と言っている。記憶を書く練習が、映像の理解そのものも少し良くした、という主張
- [AI] 伸びの多くは、箱の座標や時間帯を答える問題に集中している。同じグループが作った学習データ（VideoChat-OL・StreamForest）で同じ形式の問題を学習している影響がありそう。また、OVBench の AT のように映像なしで解ける問題や、ODV-Bench の RP のように偏りが強い問題も混ざっている
